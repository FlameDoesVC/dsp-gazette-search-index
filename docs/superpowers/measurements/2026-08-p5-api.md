## Facet cost

| doc_type | facets returned | statements | facet ms | % of request |
|---|---|---|---|---|
| shopping | 7 | 7 | 80ms p50 | 73% |

The result page itself is ~29ms at 100k docs; the facet block is 73% of the
request. This is the expected shape for N small statements over one materialized
CTE, and it is the budget to watch when P7 adds dynamic facets: if facets grow
past half the request at scale, change the N-statements shape in
`compute_facets`, not the CTE.

|---|---|---|---|
| | not yet measured | | |

The QueryLog INSERT is synchronous because the response carries `query_id`.
It is one indexed round trip on a tiny table; measure the delta at the
load-check. If it is material, switch to a client-generated id and defer the
write (the plan's stated fallback).

## Zero-result queries, first week

    WHERE result_count = 0 GROUP BY 1 ORDER BY 2 DESC LIMIT 50;

The highest-signal input for curating QueryAlias rows and finding gaps in the
transliteration table (spec 16.3). Feed the top 50 into P8's eval set.
